Forecasts every GTA VI PlayStation 5 trophy's Exophase earn rate one week after launch, as five quantiles (5%, 25%, 50%, 75%, 95%) per trophy. A damped recent logit trend with a calibrated spread; see MODEL.md for the method and backtests.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
